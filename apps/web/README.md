# @tstaff/web

برنامه کلاینت وب سامانه TStaff:
- مبتنی بر React + Vite + TypeScript.
- پشتیبانی کامل از RTL و استانداردهای طراحی فارسی.
- معماری لایه‌ای بر اساس Feature-Sliced Design:
  - `src/app`: تنظیمات کلی، Router و Providerها.
  - `src/pages`: کامپوننت‌های روت و صفحات اصلی.
  - `src/features`: فرآیندهای کاربردی (مانند فرم پذیرش، داوری گزارش).
  - `src/entities`: مدل‌های نمایشی موجودیت‌ها.
  - `src/shared`: اجزای رابط کاربری پایه (UI)، فونت‌ها و توابع ابزاری.

> **قانون قطعی:** این برنامه به هیچ وجه مجاز به ایمپورت مستقیم از `apps/api/src` یا `packages/database` نیست. تمام تایپ‌ها از `@tstaff/contracts` تأمین می‌شوند.
