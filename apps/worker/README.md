# @tstaff/worker

پردازشگر وظایف ناهمگام و رویدادهای پس‌زمینه سامانه TStaff:
- `outbox`: خواندن رویدادهای جدول `outbox_events` و ارسال به سرویس‌های مقصد (پیامک، اعلان).
- `handlers`: پردازشگران رویدادهای سیستمی (مثلاً اسکن بدافزار برای فایل‌های قرنطینه).
- `maintenance`: وظایف دوره‌ای پاک‌سازی نشست‌های منقضی، سشن‌های ناقص آپلود و بکاپ‌گیری.
