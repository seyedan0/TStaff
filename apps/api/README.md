# @tstaff/api

سرور هسته پردازشی سامانه TStaff:
- توسعه‌یافته با NestJS و TypeScript در قالب **Modular Monolith**.
- دارای ۱۷ ماژول دامنه مستقل با مرزبندی لایه‌ای:
  - `domain`: قوانین خالص کسب‌وکار و موجودیت‌ها.
  - `application`: Use Caseها، پورت‌های ورودی و خروجی.
  - `infrastructure`: پیاده‌سازی پورت‌ها، ریپازیتوری‌های دیتابیس و آداپتورها.
  - `presentation`: کنترلرها، اعتبارسنجی ورودی DTO و روت‌های HTTP.
- پلتفرم اشتراکی (`src/platform`): تنظیمات، سلامت، لاگ، رویدادها، دیتابیس و امنیت.

> **قانون وابستگی:** دسترسی به جداول پایگاه داده ماژول دیگر ممنوع است. ارتباط بین ماژول‌ها صرفاً از طریق Serviceهای عمومی مجاز اکسپورت‌شده در `index.ts` هر ماژول یا انتشار رویداد در Outbox انجام می‌شود.
