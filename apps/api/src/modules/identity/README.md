# ماژول identity

## مسئولیت و دامنه داده
حساب کاربری، ورود با گذرواژه امن، صدور و مدیریت نشست‌ها، تعلیق حساب، و ارتقای سطح عضویت (ورود با OTP و MFA به فازهای بعدی موکول شده است).

## لایه‌بندی داخلی
- domain/: موجودیت‌ها، قوانین خالص و مدل‌های تغییرناپذیر.
- application/: واسط‌های کاربردی، پورت‌ها و سرویس‌های دامنه.
- infrastructure/: ریپازیتوری‌های دیتابیس و آداپتورها.
- presentation/: کنترلرهای REST و اعتبارسنجی ورودی‌ها.

## قواعد مرزبندی
- دسترسی به این ماژول از سایر بخش‌های سیستم صرفاً از طریق توابع عمومی صادرشده در index.ts یا رویدادهای صف Outbox مجاز است.
