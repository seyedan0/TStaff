# پیش‌نمایش وب TStaff روی Vercel

## دامنه‌ی این استقرار

این استقرار فقط برای نمایش رابط وب به کارفرماست و باید روی پلن رایگان Hobby اجرا شود. API، پایگاه داده، ورود واقعی، ذخیره‌ی اطلاعات، آپلود فایل، اسکن و worker در این مرحله روی Vercel راه‌اندازی نمی‌شوند؛ پس از خرید VPS برای API وصل می‌شوند.

## پیکربندی

- ریشه‌ی پروژه در Vercel، ریشه‌ی monorepo است تا `pnpm` به `packages/contracts` دسترسی داشته باشد.
- Install command: `pnpm install --frozen-lockfile`
- Build command: `pnpm --filter @tstaff/web build`
- Output directory: `apps/web/dist`
- تمام مسیرهای وب به `index.html` بازنویسی می‌شوند تا refresh صفحه‌ی SPA خطای 404 ندهد.
- `vercel.json` همین تنظیمات را نگه می‌دارد تا build از CLI و اتصال Git یکسان باشد.
- نسخه‌ی دمو با fixtureهای مشترک وب اجرا می‌شود: میزبان محلی و `*.vercel.app` حساب‌های ساختگی، پرونده‌های پذیرش و پژوهش و فایل‌های آموزشی نمونه را نمایش می‌دهند.

## مرزهای امنیتی و رفتاری

- فایل `.env` و secrets در `.gitignore` هستند و وارد deployment نمی‌شوند.
- هیچ URL یا credential پایگاه داده، API، Vercel Blob یا VPS در bundle کلاینت قرار نمی‌گیرد.
- ورود دمو با انتخاب persona انجام می‌شود؛ داده‌های seed و پیشرفت نمایشی در `localStorage` همان مرورگر نگه داشته می‌شوند و بین مرورگرها همگام نیستند.
- API، دیتابیس، ورود واقعی، آپلود، اسکن و worker روی Vercel وجود ندارند. فایل‌های seed فقط assetهای استاتیک همین وب هستند و محتوایشان نمونه/غیررسمی است.
- ورود با شماره و گذرواژه و عملیات واقعی پس از اتصال به API روی VPS فعال می‌شوند؛ در محیط محلی می‌توان دمو را با `VITE_DEMO_MODE=false` خاموش کرد.
- Deployment را می‌توان به‌عنوان Preview یا URL نمایشی Vercel منتشر کرد؛ داده‌ی واقعی کاربران در آن قرار نمی‌گیرد.

## آماده‌سازی

1. اجرای build وب با `pnpm --filter @tstaff/web build`.
2. اتصال repository به پروژه‌ی Vercel با نام `TStaff` روی پلن Hobby، root directory برابر `.`.
3. deploy کردن Preview برای بازبینی؛ در صورت نیاز به یک URL پایدار برای کارفرما، همان نسخه‌ی نمایشی را به deployment اصلی پروژه‌ی دمو ارتقا می‌دهیم.
4. پس از خرید VPS، متغیر عمومی `VITE_API_URL` و تنظیمات امن cookie/CORS را برای API واقعی تعیین می‌کنیم؛ حالت دمو از طریق `VITE_DEMO_MODE=false` برای محیط دارای API خاموش می‌ماند.
