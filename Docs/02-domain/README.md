# مستندات دامنه و ماشین وضعیت

## وضعیت متقاضی

`PENDING -> IN_REVIEW -> APPROVED | REJECTED`

- پرونده از حساب مستقل است؛ تا تصمیم تأیید، حسابی ساخته نمی‌شود (FR-001 / BR-01).
- تخصیص اولیه مدیر علمی پس از ثبت پرونده و توسط مدیر پیگیری انجام می‌شود. وضعیت `PENDING` بدون `initialSupervisorId` یعنی «نیازمند تخصیص»؛ پیش از تخصیص، ارسال برای بررسی علمی ممکن نیست.
- رد علمی وضعیت `REJECTED` و زمان `archivedAt` را ثبت می‌کند، اما رکورد پذیرش برای تاریخچه و درخواست بازگشایی باقی می‌ماند. بازگشایی `REOPEN_REQUESTED`، زمان آرشیو را پاک می‌کند و تاریخچه رد را حفظ می‌کند.
- تأیید، وضعیت متقاضی، ساخت حساب `APPRENTICE` و انتساب مدیر علمی را در یک Unit of Work اتمی انجام می‌دهد.

## انتساب مدیر علمی (D-09 / FR-045 / FR-059)

- هر حساب حداکثر یک رکورد تاریخی مدیر علمی دارد؛ یکتایی روی `scientific_supervisor_assignments.user_id` اعمال می‌شود، از جمله پس از لغو انتساب.
- لغو، تعلیق حساب مدیر یا حذف نقش، تاریخچه را پاک نمی‌کند و امکان تعیین مدیر دیگری نمی‌دهد.
- پرونده پژوهش باید پژوهشگر داشته باشد و مدیر علمی فعال آن باید دقیقاً با مدیر یکتای پژوهشگر برابر باشد.
- `COLLABORATOR_SUPERVISOR` در enum فقط برای تشخیص سابقه قدیمی باقی مانده است؛ درج/به‌روزرسانی آن در دامنه و پایگاه داده رد می‌شود.
- نقش سیستمی `SCIENTIFIC_SUPERVISOR` به‌تنهایی مجوز مشاهده یا داوری نمی‌دهد؛ مجوز از انتساب همان فرد و وضعیت منابع محاسبه می‌شود.
- نخستین تصمیم معتبر روی نسخه جاری نتیجه را ثبت می‌کند؛ تصمیم بعدی برای نسخه قدیمی با `409 STALE_REVISION` رد می‌شود (D-02 / FR-057 / AT-29).

## وضعیت رشد کاربر

`APPRENTICE -> INTERN`

- وضعیت حساب: `ACTIVE | SUSPENDED | CLOSED_ARCHIVED`.
- کارآموز تا تأیید مطالعه منابع و تصمیم مدیر علمی یکتای خود اجازه ایجاد پژوهش ندارد.

## وضعیت مراحل پژوهش

`DRAFT -> SUBMITTED -> CHANGES_REQUESTED | APPROVED`

- وضعیت اعتبار وابستگی: `VALID | REVIEW_REQUIRED`.
- بازگشت یا تغییر پیش‌نیاز، خروجی‌های وابسته را نیازمند بازبینی می‌کند و نسخه‌های تاریخی را حذف نمی‌کند (D-05 / FR-061 / AT-33).

## سایر قیود دامنه

- هر منبع حداکثر یک مصاحبه و هر مصاحبه نسخه‌های گزارش مستقل دارد؛ تکمیل مرحله منابع تنها با وجود مصاحبه و گزارش برای تمام منابع پذیرفته می‌شود (D-07 / FR-058 / AT-30).
- سن متقاضی و مصاحبه‌شونده عدد صحیح مثبت است؛ از تاریخ تولد مشتق نمی‌شود (D-01 / FR-056 / AT-28).
- اعلان فوری نظارتی فقط برای رخدادهای حساس صادر می‌شود؛ همه رویدادها در ممیزی قابل جست‌وجو می‌مانند (D-04 / FR-060 / AT-32).
