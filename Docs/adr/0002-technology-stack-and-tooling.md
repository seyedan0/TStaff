# ADR-0002: انتخاب پشته فناوری و ابزارهای توسعه (Technology Stack)

- **شناسه:** ADR-0002
- **عنوان:** تعیین فریم‌ورک‌ها، زبان‌ها و کتابخانه‌های پایه فرانت‌اند، بک‌اند و پایگاه داده
- **وضعیت:** پیشنهادی (مطابق بخش ۴ پروپزال فنی)
- **تاریخ:** ۲۰۲۶-۱۱-۰۷ (۱۶ آبان ۱۴۰۵)
- **مالک:** مسئول فنی پروژه
- **مرجع نیازمندی:** پروپزال فنی v0.1 بخش ۴، ۱۶ و ۱۷؛ جدول تصمیمات DEC-001 و ADR-002/003/004

---

## ۱. زمینه و مسئله (Context)
تیم فنی توسعه پروژه با پشته TypeScript/Node.js/React فعالیت می‌کند. نیازمندی‌های سامانه شامل پنل‌های مدیریتی غنی، پشتیبانی کامل از زبان فارسی و چینش راست‌به‌چپ (RTL)، تراکنش‌های امن پایگاه داده، و پشتیبانی از قراردادهای نوع‌داده‌ای قوی (Type-safety) در تمام لایه‌ها است.

---

## ۲. تصمیم (Decision)
1. **زبان:** TypeScript نسخه strict (برای تمام برنامه‌ها و بسته‌ها).
2. **رابط کاربری (Frontend):**
   - React + Vite با ساختار Feature-sliced/Layered.
   - استایل‌دهی با Tailwind CSS و اجزای دسترس‌پذیر بر پایه استانداردهای shadcn/ui.
   - مدیریت داده و کش سرور با TanStack Query.
   - فرم‌ها و اعتبارسنجی با React Hook Form و Zod.
3. **سرور و API (Backend):**
   - NestJS با پروتکل REST و استاندارد OpenAPI (Swagger) در مسیر `/api/v1`.
   - ارتباطات بلادرنگ چت با Socket.IO.
4. **پایگاه داده و نگاشت (Database & ORM):**
   - PostgreSQL به عنوان پایگاه داده رابطه‌ای تراکنشی.
   - Drizzle ORM به عنوان لایه ارتباطی با پایگاه داده و مدیریت Migrations مبتنی بر SQL.
5. **مدیریت مخزن و وابستگی‌ها:**
   - pnpm Workspaces برای مدیریت ساختار چندبسته‌ای (Monorepo).

---

## ۳. گزینه‌های جایگزین (Alternatives)
- **Next.js (App Router):** به دلیل اینکه سامانه عمدتاً پنل مدیریت و کارتابل احراز هویت‌شده است و نیازی به سئو (SEO) یا رندر سمت سرور عمومی ندارد، React + Vite به دلیل سبکی و سادگی بیلد انتخاب شد.
- **Prisma:** به دلیل سربار بیلد موتور باینری، پیچیدگی در برخی سناریوهای تراکنشی پیشرفته و همزمانی، Drizzle به دلیل نزدیکی به SQL استاندارد و سبکی ترجیح داده شد.

---

## ۴. پیامدها (Consequences)
- هماهنگی و اشتراک تایپ‌ها بین کلاینت و سرور از طریق پکیج `contracts`.
- شفافیت کامل در کدهای مهاجرت دیتابیس (SQL-first migrations).
- استقرار بهینه و سبک با کانتینرهای Docker در محیط‌های VPS ایران.
