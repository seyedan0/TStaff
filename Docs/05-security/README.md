# مدل امنیت و احراز اصالت/مجوز (Security & Authorization)

## ماتریس تصمیم مجوز (Policy Evaluation)
هر تصمیم مجوز (AuthZ) حاصل رابطه زیر است:
`Decision = evaluate(Role, Action, TargetEntity, Scope(Province/Case), CurrentState, Delegation)`

## اصول امنیتی
- **نشست‌های امن (Secure Sessions):** کوکی‌های `HttpOnly` و `SameSite=Lax/Strict` همراه با محافظت CSRF.
- **تأیید دوعاملی (MFA):** فعال برای تمام نقش‌های مدیریتی (مدیر استانی، علمی، پیگیری، مدیر کل).
- **لغو بلادرنگ دسترسی:** تعلیق کاربر فوراً نشست و دسترسی‌های وب‌سوکت را باطل می‌کند.
- **فایل‌های ایمن:** آپلود فقط با شناسه یکتای تصادفی، اسکن ضدبدافزار، و دسترسی با لینک‌های امضاشده کوتاه‌عمر.
